## Acerca del Proyecto

[![Product Name Screen Shot][product-screenshot]](https://example.com)

Este proyecto fue desarrollado como parte del curso de Ingeniería de Software 1 en la Universidad del Valle de Guatemala. El objetivo principal es aplicar los conceptos y prácticas de ingeniería de software en un proyecto real, desde la planificación hasta la implementación.
